1. 对[2, -3, 4]，最后总和是多少、动态和列表是什么？为什么不能只返回最后总和？用自己的变量解释累计到了哪里。
最后总和是3,动态和列表是[2,-1,3],只返回最后总和有可能是通过多轮for循环每次都从第一个数开始相加得到的，但是动态和列表可以确保每次只加一次

2. 为什么double result = 7 / 2得到的数值不是3.5？怎样让这次除法保留小数，原因是什么？
double result = 7 / 2，7和2都是int，所以7 / 2得到3，double只会将3从int转换为double，并不会补全3.5，double result = 7.0 / 2即可，7.0让编译器视为浮点数

3. 对今天神经元，调用forward十次会自动学到参数吗？你写的fit依据什么选weight、保存在哪里？为什么只检查A的第一条样本不够？
不会自动学到参数，fit依据预测值与真实值是否相同选择weight，保存在ys_hat这个列表中，只检查A有可能是恰好满足A的这一条样本
