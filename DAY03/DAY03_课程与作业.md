## 第一部分：input()得到的永远先是文字

运行下面代码时，即使输入`18`，`input()`得到的也是字符串`"18"`：

```python
age_text = input("请输入年龄：")
print(type(age_text))
```

为什么？键盘只负责把你敲进去的字符交给程序。程序不知道`18`是年龄、编号还是姓名的一部分，所以先把它当文字最安全。

如果要做数字比较，需要主动转换：

```python
age_text = input("请输入年龄：")
age = int(age_text)
print(age >= 18)
```

也可以合并写成：

```python
age = int(input("请输入年龄："))
```

`int()`只能转换像`"18"`、`"-3"`这样的整数字符串。输入`"十八"`或`"3.5"`会报错；异常处理以后专门学习，今天先按要求输入整数。

## 第二部分：and、or、not

## and：所有条件都要成立

```python
months >= 3 and weekly_hours >= 20
```

只有实习月数至少3个月，并且每周至少20小时，整个条件才是True。

| 条件A | 条件B | A and B |
|---|---|---|
| True | True | True |
| True | False | False |
| False | True | False |
| False | False | False |

## or：至少一个条件成立

```python
score < 0 or score > 100
```

分数小于0或者大于100，任意一个发生，都说明输入无效。

| 条件A | 条件B | A or B |
|---|---|---|
| True | True | True |
| True | False | True |
| False | True | True |
| False | False | False |

## not：把真假反过来

```python
has_experience = False
print(not has_experience)
```

`not False`得到True，`not True`得到False。今天的必做题不强制使用`not`，但要能读懂。

## 第三部分：为什么判断顺序很重要

假设按分数划分等级，应该先检查分数是否合法：

```text
先判断：小于0或大于100吗？
再判断：达到90吗？
再判断：达到80吗？
……
```

如果一开始写`score >= 90`，那么输入`105`也会被错误判断为优秀。

多个`elif`从上到下检查，一旦某个条件为True，后面的分支就不再执行。因此通常从更严格、更特殊的条件写到更普通的条件。

## 第四部分：手敲跟做程序

打开`DAY03/01_跟做_实习申请资格.py`，不要复制粘贴，照着下面内容逐行手敲：

```python
months = int(input("最多可以连续实习几个月："))
weekly_hours = int(input("每周可以实习多少小时："))
python_answer = input("是否学过Python（Y/N）：")
knows_python = python_answer == "Y"

is_eligible = months >= 3 and weekly_hours >= 20 and knows_python

if is_eligible:
    print("满足基本申请条件")
else:
    print("暂时不满足基本申请条件")

    if months < 3:
        print("原因：可实习月数不足3个月")
    if weekly_hours < 20:
        print("原因：每周时间不足20小时")
    if not knows_python:
        print("原因：还没有Python基础")
```

这段代码包含“嵌套判断（nested condition）”：外层先判断是否满足，失败后再用三个内层`if`分别说明原因。三个原因可能同时出现，所以这里不用`elif`。

|---:|---:|---|---|
| 4 | 25 | Y | 满足 |
| 2 | 25 | Y | 月数不足 |
| 4 | 10 | N | 同时输出时间和Python两个原因 |

## 第六部分：必做二——三个整数中的最大值

打开`DAY03/03_独立_三个整数最大值.py`。

分别输入三个整数，在不使用内置`max()`的情况下输出最大值。

推荐算法思路：

```text
先假设第一个数最大
如果第二个数更大，就更新“当前最大值”
如果第三个数更大，再更新“当前最大值”
最后输出当前最大值
```

这个方法比列出所有数字大小关系更简洁，也为以后学习循环做准备。

测试：

- `3、8、5` → 8
- `9、2、9` → 9
- `-3、-8、-1` → -1
- `4、4、4` → 4
