## 二、先回答你的心得：不是只差一个1/2

### 1. 三个量必须分开看

固定标签`[1, 1]`、预测`[0, 2]`。先逐条计算“预测−标签”，得到误差`[-1, +1]`。

| 名称 | 算什么 | 本例结果 | 能否正负抵消 |
|---|---|---:|---|
| 带符号平均误差（mean signed error） | 先相减，再直接平均 | `(−1+1)/2 = 0` | 会 |
| 均方误差（mean squared error，MSE） | 每条误差先平方，再平均 | `(1+1)/2 = 1` | 不会 |
| 本课平均损失，即半均方误差 | 每条平方误差除以2，再平均 | `(0.5+0.5)/2 = 0.5` | 不会 |

所以：**后两行才只差1/2；第一行与后两行的关键区别是先不先平方。** 带符号平均误差可以看出整体偏高还是偏低，但相互抵消后不能独自衡量这批预测错得多大。

你问“哪个带1/2”时，还要注意另一个容易混淆的2：本例有两条样本，所以“求平均”也要除以2。它与单条损失里固定的1/2是两回事。

换成三条样本时，MSE要除以3，本课平均损失要除以`2×3`；其中3来自样本数，2来自损失定义。不是所有“除以2”都来自平方损失。

你实际写的SquaredLoss是第三行，代码正确。现在要补的是把概念名称对应到你已经写出的计算，不是否定这份实现。

### 2. 既然1/2方便求导，为什么还会用不带它的MSE

因为它只是一个方便推导的**固定缩放系数**，不是平方误差正确与否的开关。

MSE直接表示“平方误差的平均值”，定义简洁，常用作报告误差的指标。教材在优化推导中乘1/2，是为了让平方求导产生的2被约掉；计算机处理多一个2并不困难，所以软件没必要全部采用教材的约定。例如PyTorch的MSELoss默认计算平方误差的平均值，不带额外1/2。[官方定义](https://docs.pytorch.org/docs/2.14/generated/torch.nn.modules.loss.MSELoss.html)

对于只包含这项误差的同一个优化目标，全部乘正数1/2，不改变哪套参数使它最小；但损失数值和导数都会减半。以后按导数更新参数时，同样的学习率会产生不同大小的更新，因此不能说“有没有1/2，在任何地方都完全没区别”。

今天不安装PyTorch，只用这个例子说明：看到名字相近的损失，先核对公式。本阶段继续统一采用`(预测−标签)²/2`，避免来回换定义。

class Solution:
    def search(self, nums, target):
        left = 0
        right = len(nums) - 1

        while left <= right:
            mid = (left + right) // 2
            if nums[mid] < target:
                left = mid + 1
            elif nums[mid] > target:
                right = mid - 1
            else:
                return mid
        return -1

## 五、Python：二分没找到，留下来的边界有什么用

### 1. 35比704多问了什么

704找不到就交−1。今天希望在不破坏升序的情况下插入一个数，**只报告它应该放的下标，不真的插入**。

例如数组`[2, 5, 9, 14]`中找7，没有7，但它应该排在5后、9前，插入位置为2。找20应该排在末尾，位置为4。4等于数组长度：它是允许的插入位置，却不是原数组可以读取的下标。

今天仍使用昨天的闭区间`[left, right]`。不同时讲左闭右开、递归和其他模板，先把这一种区间含义贯通。

### 2. 从“剩下可能有答案的部分”，看到“两侧已经知道的事实”

闭区间二分不仅保存候选区间，也不断产生确定信息：

- left左边那些位置，已经确定数值小于target。
- right右边那些位置，已经确定数值大于target。
- 中间如果碰到相等值，直接得到原下标。

用`[2, 5, 9, 14]`找7：

| 候选区间 | 本次查看 | 比较结果 | 新边界 |
|---|---|---|---|
| 0—3 | 下标1的5 | 5小于7 | left到2，right仍3 |
| 2—3 | 下标2的9 | 9大于7 | right到1，left仍2 |

现在left=2、right=1，没有候选位置了。但不是“什么也没留下”：下标0、1的数都小于7；下标2之后的数都大于7。新数应放在两部分的交界处。

**在本课这套闭区间写法中，查找失败后，left就是这个交界位置，也等于right+1。** 这不是脱离条件的口诀：如果换了区间定义或更新规则，必须重新说明边界含义。

### 3. 插入位置与现有下标为什么范围不同

有n个元素，已有元素下标为0到n−1；可插入的位置从0到n，共n+1处，包括最前和最后。

- 目标比所有元素小：位置0。
- 目标比所有元素大：位置n。
- 目标已存在：返回那个已有下标，不产生重复元素。

返回n是合法的，访问`nums[n]`却越界。我们只是在计算位置，不需要为了“插入”扩容、排序或移动元素。若真去插入并搬移后面的元素，也不再是这道题所需的O(log n)查找过程。

## 六、C++：下标读写和独立副本

### 1. 昨天会保存，今天要修改其中一条

假设vector里存着三次耗时`[12, 20, 8]`，发现第二条录错了，需要改成25。追加25会多一条数据，并没有修正第二条；应该按下标替换已有元素。

**下标访问（indexing）**用`values[index]`取对应位置的元素；放在赋值号左边，则修改那个位置。下标0对应第一项，1对应第二项。修改已有元素不改变size；push_back才是末尾追加。[vector下标的官方说明](https://learn.microsoft.com/en-us/cpp/standard-library/vector-class?view=msvc-170#op_at)

这个独立小例子只演示读写，不替你完成读入和整组输出：

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> values = {4, 9};
    std::cout << values[1] << "\n";
    values[1] = 6;
    std::cout << values[1] << "\n";
    std::cout << values.size() << "\n";
    return 0;
}
```

输出9、6、2。把下标1改成0时，读取和修改的是第一项，长度同样不变。你昨天已经能用下标读取，今天重点是有目的地修改，而不是再复习一整节遍历。

### 2. 下标合法不等于“看起来能运行”

vector长度为n，合法元素下标是0至n−1。长度2时，`values[2]`不是第三个空位置，而是越界；空vector没有可读写的元素。

C++17的`operator[]`不负责为你做可靠的边界检查，越界属于**未定义行为（undefined behavior）**：结果没有保证，可能崩溃，也可能似乎跑完，不能拿一次运行正常证明写对。不需要故意运行越界代码来体验它。

今天题目保证输入下标合法，先不增加异常处理、指针或底层内存知识。输出全部内容时仍可用已经会的范围for。

### 3. 复制一份再试改，原始记录是否会跟着变化

希望试着调整某条耗时，但保留原始记录，可以创建**副本（copy）**。对于本课的`std::vector<int>`，用现有vector初始化另一个vector，会复制元素到独立容器里：

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> original = {4, 9};
    std::vector<int> copy = original;
    copy[0] = 30;
    std::cout << original[0] << "\n";
    std::cout << copy[0] << "\n";
    return 0;
}
```

输出4、30；对copy的修改没有改original。复制n个整数需要O(n)时间和额外空间，不是免费操作。现在只讨论整数vector，不扩展到装指针或嵌套对象的情形。

别把这个行为直接套到Python列表。Python的`copy = original`只让两个名字指向同一列表；若需要本课这种整数列表的独立副本，可用`original.copy()`。它不接收参数，返回一个新列表，原列表不变。例如：

```python
original = [4, 9]
copy = original.copy()
copy[0] = 30
print(original)  # [4, 9]
print(copy)      # [30, 9]
```

这里只做语言差异提醒，不另加Python题。`.copy()`是浅拷贝，当前元素都是整数足够；嵌套可变对象留到以后。[Python官方列表说明](https://docs.python.org/3/tutorial/datastructures.html#more-on-lists)

## 七、模型：从“错了多少”，走到“参数该往哪边动”

本节核对[本地《神经网络与深度学习》](../../学习资料/AI%20agent/神经网络与深度学习%20%28邱锡鹏%29.pdf)：2.2.3开头，**书内29—30页/PDF44—45页**；附录B.1.1的导数与偏导数，**书内394—395页/PDF409—410页**，重点公式(B.1)。附录图B.1说明局部斜率，表B.1列出常见求导形式。今天只取所需内容，不通读积分、泰勒展开或矩阵微积分。

### 1. 先把昨天的结果变成今天的问题

你已经算出LinearNeuron(1,0)在四条数据上的平均损失为1.75，而LinearNeuron(2,1)是0。昨天是人提前知道第二组参数好；真实任务里通常不知道最佳参数，不能靠把答案参数写进初始化来完成学习。

想让机器改参数，就先得回答：“现在把weight增大一点，损失会增大还是减小？”损失提供评分，但没有直接给这个方向；今天学的导数，就是把“变化的方向和快慢”表达出来。

**优化（optimization）**是寻找让目标更小的参数。今天先学怎样测方向；明天再学怎样决定每次走多远并真正更新。

### 2. 先不看公式，只改一个旋钮

仍用一个线性神经元，先只看固定样本x=2、标签y=5。固定b=0，把w从1变成1.1：

| w | 预测w×2 | 误差预测−5 | 单条损失 |
|---:|---:|---:|---:|
| 1 | 2 | −3 | 4.5 |
| 1.1 | 2.2 | −2.8 | 3.92 |

weight增加0.1，损失减少0.58。只看“减少0.58”还没有考虑改了多大的weight，因而用变化量相除：

```text
变化率 = 损失变化量 / 权重变化量
       = (3.92 − 4.5) / (1.1 − 1)
       = −5.8
```

**平均变化率（average rate of change）**衡量这一小段里，参数每变化一个单位，损失平均变化多少。负号表示这段里w增大、损失减小，不表示损失本身变成负数。

这个−5.8不表示“把w一次加1，损失就一定减5.8”；我们只测了1到1.1这一段，离开它后变化快慢可能不同。

### 3. 从小段变化率，逐渐接近当前位置的导数

把本次微小变化记作h，它表示“试探的距离”，不是模型输入x，也不是标签y。在同一点w=1重新开始，每次只换h：

| h | 新w | 新损失 | `(新损失−4.5)/h` |
|---:|---:|---:|---:|
| 0.1 | 1.1 | 3.92 | −5.8 |
| 0.01 | 1.01 | 4.4402 | −5.98 |
| 0.001 | 1.001 | 4.494002 | −5.998 |

变化率越来越接近−6。**导数（derivative）**就是在可导时，让试探距离趋近0后得到的局部变化率；人话：这一个位置上，往旁边挪一点，损失最初会怎样变。

教材公式(B.1)就是“新函数值减旧函数值，再除以输入变化量，最后看变化量趋近0时的结果”。其中的lim表示“趋近时的极限”，不是把h直接设为0做除法。

今天代码用一个非零的小h做**数值近似（numerical approximation）**，所得变化率接近导数但通常不完全相等。h太大反映一大段平均趋势；也不是越小越好，因为计算机浮点数精度有限。今天用0.1和0.01即可，不追求极小数值。

### 4. 不背规则，也能看出平方求导为什么有一个2

先把误差写成e；它就是预测减标签。我们把e增加h：

```text
(e+h)² = (e+h)×(e+h) = e² + 2×e×h + h²

平方的变化率 = ((e+h)² − e²) / h
             = 2×e + h
```

当h趋近0，最后一项趋近0，得到2e。所以e²对e的导数是2e；如果原函数是e²/2，变化率也整体除以2，导数就是e。

这正好回答你的疑问：教材的1/2不是用来防止正负抵消的，**平方**才负责这件事；1/2只是让这里出现的2约掉。不带它，数学仍然成立，导数多一个2而已。

现在回到真实模型：`e = w×x+b−y`。固定x、y、b，把w增加h，误差不是增加h，而是增加`x×h`。

```text
新误差 = e + x×h
损失变化率 = ((e+x×h)²/2 − e²/2) / h
           = e×x + x²×h/2
```

h趋近0，后一项消失，得到单样本损失对w的导数`e×x`。刚才e=−3、x=2，所以是−6，和数值试探一致。

这不是凭空扔来的梯度公式：w先影响预测，预测影响误差，误差再影响平方损失。今天先把这一小段乘法关系算通，不要求多层网络的链式求导。

### 5. 同时有w、b，为什么要说“偏导数”

损失L(w,b)依赖两个参数。只动w、固定b，得到对w的**偏导数（partial derivative）**；只动b、固定w，得到对b的偏导数。人话：有两个旋钮，一次只拧一个，才能知道是谁让损失变了。

固定w，b增加h时，误差增加h，所以同样推理得到单样本损失对b的偏导数为e。对x=2、y=5、w=1、b=0这条样本：

| 只变化谁 | 其他量 | 当前位置的偏导数 |
|---|---|---:|
| w | b、x、y固定 | e×x = −6 |
| b | w、x、y固定 | e = −3 |

偏导数写成`∂L/∂w`、`∂L/∂b`，可以直接读作“L对w、对b的变化率”。此处目标是改变参数，不是偷偷修改样本x或标签y来降低损失。

如果w、b同时增加，再把损失变化除以h，测到的是两者一起变化的效果，不能称为对w单独的偏导数。把各个参数的偏导数放在一起叫**梯度（gradient）**；本课先认识它是“每个旋钮各自的变化信息”，下一课再用它更新。

负偏导数提示：当前位置把这个参数增大足够小的一点，损失会降低；正偏导数则提示反方向。导数为0并不在任何函数上都保证找到了最小值，今天不把“0”当作万能训练终点。

### 6. 从一条样本，回到你昨天的四条数据

训练不是只照顾x=2这一条。仍用四条数据，平均损失记作J(w,b)，基准参数w=1、b=0时J=1.75。

只把w改成1.1、b保持0，重新走“取样→预测→单条损失→平均”，得到1.5575；其变化率为`(1.5575−1.75)/0.1 = −1.925`。它不等于单条样本的−5.8，因为这里评分包含了四条数据。

今天代码重复评估整批数据，观察变化率逐渐接近什么；不用直接背多样本梯度公式。DAY26会进一步把每条梯度与平均梯度对应起来。

### 7. 面向对象：让一个评估对象组织已有部件

昨天你给三种模型分别写了三段很像的循环。如果今天每换一个邻近权重都再复制一段，容易忘记改某一处，也容易再次绕过get_item。

新增**LossEvaluator，损失评估器**：保存一份数据集对象和一个损失对象；每次接收不同模型，返回这个模型在固定数据上的平均损失。这是**对象组合（object composition）**的实际用途：一个对象使用其他对象完成稍大的任务，不需要继承。

- `self.dataset`保存数据集对象，不是单个数字x；取样通过它的size和get_item。
- `self.loss`保存你已经实现的SquaredLoss对象，不是某次损失的数值。
- evaluate方法本次接收model。它负责根据x预测；换模型不需要重新创建数据集。
- 本次预测列表和标签列表是方法里的局部数据，每次调用重新产生，不混入上次结果。

读取`self.dataset.get_item(i)`是在请数据集给出样本；调用`model.forward(x)`是在请本次传入的模型预测；调用`self.loss.mean(...)`是在请损失部件评分。对象各自负责自己的计算，评估器只负责把它们连接起来。

这次自然修复并验证get_item，但重点是新增“可重复评估邻近参数”的能力，不让你重抄所有旧类。
