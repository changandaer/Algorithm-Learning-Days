### 示范 7：两数之和暴力搜索

```python
numbers = [2, 7, 11, 15]
target = 9
found = False

for first_index in range(len(numbers)):
    for second_index in range(first_index + 1, len(numbers)):
        current_sum = numbers[first_index] + numbers[second_index]

        if current_sum == target:
            print(
                f"找到索引 {first_index} 和 {second_index}："
                f"{numbers[first_index]} + {numbers[second_index]} = {target}"

```

对比和评语：

## 三、DAY05 理论题示范答案

### 1. 为什么索引从 0 开始？

索引可以理解为“距离列表开头偏移了几个位置”。第一个元素没有偏移，所以是 0；五个元素的索引是 0～4，最后一个有效索引为 4。

### 2. `append()` 与索引赋值有什么区别？

`append()` 在列表末尾增加新元素，列表长度通常加一；`skills[1] = "linux"` 是替换已有位置的内容，列表长度不变。给不存在的索引赋值还会越界报错。

### 3. 什么是遍历？

遍历是按顺序处理容器中的每个元素。只关心内容时直接遍历元素；需要位置、相邻元素或修改指定位置时遍历索引。

### 4. 为什么执行 `strip().lower()`？

它把首尾空格和英文大小写差异统一掉，让 `" Python "` 与 `"python"` 能被视为同一项技能。标准化必须同时应用于被比较的两边。

### 5. O(n) 用人话怎样解释？

线性查找最坏要比较 n 次。数据量扩大十倍时，最坏工作量大致也扩大十倍；O(n) 描述的是数据变多时工作量增长的趋势。

### 6. 最低损失为什么不能初始化为 0？

如果所有真实损失都大于 0，任何值都不会比初始 0 更小，程序会错误地把不存在于数据中的 0 当作最低损失。应使用第一条真实数据初始化。

### 7. 内层索引为什么从 `first_index + 1` 开始？

假设外层已经选择索引 1，内层就只检查索引 2 及其后面的位置。这样不会让索引 1 与自己配对，也不会重复检查之前已经出现过的反向组合。

## 四、真正的重点：六格拆题法

拿到题目后，不要立即问“需要几个变量”，也不要马上写 `for`。先用纸、注释或脑中回答六个问题。

### 第 1 格：输入是什么？

输入是一个数、一行文字、一个列表，还是多次用户输入？数据类型是什么？

### 第 2 格：输出是什么？

最终要打印什么？只要数值，还是还要索引、次数、清单？把输出逐字读清，防止像 DAY05 那样漏掉完整列表和索引。

### 第 3 格：拿最小样例手算一次

不要在脑中直接处理五十个数据。选 2～4 个数据，像人一样一步步算，把中间变化写出来。

### 第 4 格：手算时必须记住什么？

这才是变量的来源。例如：

- 求和必须记住目前总和。
- 查找必须记住是否找到、找到的位置。
- 两数之和必须记住两个不同位置。
- 去重必须记住已经收录的内容。

变量不是凭空猜数量，而是为“必须记住的事实”准备盒子。

### 第 5 格：哪些动作会重复？

逐个处理数据通常使用一层循环；让每个元素与后面的元素逐对组合，通常使用两层循环；不知道第几次结束时使用 `while`。

先写中文伪代码，只表达动作，不纠结 Python 拼写。

### 第 6 格：什么输入最容易拆穿错误？

至少准备：普通情况、边界情况、找不到的情况，以及专门针对自己判断逻辑的反例。

例如两数之和不能只测目标 9，还要测目标 4。目标 4 会专门检查程序是否错误地重复使用数字 2 所在的同一位置。

## 五、跟做示范：定位第一次损失反弹

### 题目

给定训练损失：

```python
losses = [1.0, 0.8, 0.6, 0.7, 0.5]
```

损失正常趋势通常是下降。找出第一次比前一轮更高的位置，输出前一轮、本轮和两个损失；如果一直没有升高，输出“没有反弹”。

### 用六格法拆解

1. 输入：已经给定的浮点数列表。
2. 输出：第一次反弹的两个轮次及数值，或者没找到。
3. 手算：1.0→0.8 下降，0.8→0.6 下降，0.6→0.7 上升，所以第 4 轮第一次反弹。
4. 状态：是否找到反弹；当前索引。
5. 重复动作：从第二个元素开始，每个元素与前一个元素比较。
6. 测试：规定列表会反弹；`[1.0, 0.8, 0.6]` 不反弹；`[1.0, 1.1]` 立即反弹。

伪代码：

```text
先假设没有反弹
索引从 1 走到列表末尾
    如果当前损失大于前一个损失
        输出第一次反弹信息
        记录已经找到
        停止循环
如果最终仍未找到
    输出没有反弹
```

### 分段手敲

```python
losses = [1.0, 0.8, 0.6, 0.7, 0.5]
found_rebound = False
```

```python
for current_index in range(1, len(losses)):
    previous_index = current_index - 1

    if losses[current_index] > losses[previous_index]:
        print(
            f"第 {previous_index + 1} 轮到第 {current_index + 1} 轮发生反弹："
            f"{losses[previous_index]} -> {losses[current_index]}"
        )
        found_rebound = True
        break
```

```python
if not found_rebound:
    print("损失没有反弹")
```

这里索引从 1 开始，是因为索引 0 没有前一个元素可比较。
