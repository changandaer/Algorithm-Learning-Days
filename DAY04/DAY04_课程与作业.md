## 三、今天只学一个知识组：循环

### 1. 为什么需要循环

如果要输出 1 到 5，可以写五次 `print()`。如果要输出 1 到 10000，复制一万次显然不现实。

**循环（loop）**就是让计算机按照规则重复做一件事。重点不是“重复”，而是每重复一次，程序的状态通常会发生一点变化。

```python
for number in range(1, 6):
    print(number)
```

这里的 `range(1, 6)` 会产生 `1、2、3、4、5`，不包含 6。可以把第二个数字理解成一道不能踩进去的终点线。

### 2. `for` 循环：次数或范围明确

当你知道要处理多少个数字，或者知道从哪里数到哪里时，优先考虑 `for`。

```python
for number in range(1, 4):
    print("本轮数字：", number)
```

执行过程不是三行代码同时运行，而是：

1. `number` 先取 1，执行缩进代码。
2. `number` 再取 2，执行缩进代码。
3. `number` 再取 3，执行缩进代码。
4. 没有下一个数字，结束循环。

常见 `range()`：

```python
range(5)        # 0、1、2、3、4
range(1, 5)     # 1、2、3、4
range(2, 11, 2) # 2、4、6、8、10，第三个数表示每次走几步
```

### 3. `while` 循环：什么时候结束由条件决定

如果不知道用户第几次才会输入正确内容，只知道“输入不正确就继续问”，适合使用 `while`。

```python
score = int(input("请输入 0 到 100 的成绩："))

while score < 0 or score > 100:
    print("输入无效，请重新输入")
    score = int(input("请输入 0 到 100 的成绩："))

print("最终有效成绩：", score)
```

`while` 可以理解为门卫：只要门口条件仍然为真，就不让程序往下走。

最危险的问题是**死循环（infinite loop）**：条件一直为真，程序永远停不下来。例如忘记在循环里重新读取 `score`，旧的错误分数就永远不会改变。

### 4. 累计器和计数器

**累计器（accumulator）**用来不断合并结果，例如求和：

```python
total = 0

for number in range(1, 6):
    total = total + number

print(total)
```

`total = total + number` 不是数学等式。它的意思是：先算右边，再把新结果放回左边的盒子。也可以简写成：

```python
total += number
```

**计数器（counter）**专门记录发生了几次：

```python
positive_count = 0

number = int(input("请输入整数："))
if number > 0:
    positive_count += 1
```

累计器常常增加不同的数，计数器通常每次只加 1。

### 5. “到目前为止都正确”的思维

专业上把它叫作**循环不变量（loop invariant）**。不用背名字，先理解这句话：

> 每一轮结束时，手里的结果都必须正确代表“目前已经处理过的内容”。

DAY03 最大值题中的 `current_max` 就是例子。处理完前两个数后，它必须是前两个数的最大值；处理完第三个数后，它必须是三个数的最大值。每次都和 `current_max` 比，规则才不会断。

### 6. `break`：提前结束循环

`break` 表示“目标已经完成，现在立刻离开本层循环”。猜数字时，猜中以后就不需要继续问：

```python
while True:
    guess = int(input("请猜数字："))
    if guess == 37:
        print("猜中了")
        break
```

`while True` 本来会一直运行，因此内部必须存在一个确实有机会执行的 `break`。初学阶段不要滥用这种写法，只有结束条件放在循环中间时再使用。

## 四、跟做：从 1 累加到 n

### 先说清输入和输出

- 输入：一个正整数 `n`。
- 输出：从 1 到 `n` 的所有整数之和。
- 例子：输入 5，输出 15，因为 `1 + 2 + 3 + 4 + 5 = 15`。

### 数据和步骤

- `n`：用户规定的终点。
- `total`：保存目前已经加出的总和，初始为 0。
- `number`：本轮要加入总和的数字。

伪代码：

```text
读取 n
把 total 设为 0
让 number 从 1 走到 n
    把 number 加进 total
输出 total
```

### 分段手敲，不要整段复制

先在 `01_跟做_for循环求和.py` 手敲输入与初值，运行并确认没有报错：

```python
n = int(input("请输入一个正整数："))
total = 0
```

然后加循环。注意为了包含 `n`，终点写 `n + 1`：

```python
for number in range(1, n + 1):
    total += number
```

最后输出：

```python
print("从 1 到", n, "的和是：", total)
```

必须测试：

| 输入 | 预期输出中的结果 |
|---:|---:|
| 1 | 1 |
| 5 | 15 |
| 10 | 55 |

手工跟踪 `n = 3`：

| 循环轮次 | `number` | 加之前的 `total` | 加之后的 `total` |
|---:|---:|---:|---:|
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |
