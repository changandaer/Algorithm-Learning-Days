1. 为什么 `range(1, 6)` 不会取到 6？
因为range函数类似于左闭右开的区间范围，只能取到6-1，也就是5

2. 什么情况适合 `for`，什么情况适合 `while`？
明确知道循环次数的时候适合用 for循环，不知道明确的循环次数或循环次数由一个判断条件确定的时候适合用 while循环

3. 求和时为什么 `total` 要从 0 开始，并且放在循环外？
因为累加要从0开始，放在循环内会导致每一次循环 total 都被重新赋值为 0

4. DAY03 最大值程序为什么在 `10、1、5` 时出错？
因为我错误的将 c 与 b 进行了对比，而不是将 c 与 a和b的最大值 current_max 进行对比

5. `while` 为什么会形成死循环？怎样避免？
while 后条件为 True 就会一直执行，避免 while 后的条件永远是 True 这种情况出现
