### 1. 283：把新列表上的写入改到原列表

```python
class Solution:
    def moveZeroes(self, nums):
        write = 0
        for read in range(len(nums)):
            if nums[read] != 0:
                nums[write] = nums[read]
                write += 1

        for index in range(write, len(nums)):
            nums[index] = 0


solution = Solution()
nums = [0, 5, 0, -2, 5]
result = solution.moveZeroes(nums)
assert nums == [5, -2, 5, 0, 0]
assert result is None
nums = [0]
solution.moveZeroes(nums)
assert nums == [0]
nums = [0, 0, 0]
solution.moveZeroes(nums)
assert nums == [0, 0, 0]
nums = [4, -1, 4]
solution.moveZeroes(nums)
assert nums == [4, -1, 4]
nums = [7, 0]
solution.moveZeroes(nums)
assert nums == [7, 0]
nums = [0, 7]
solution.moveZeroes(nums)
assert nums == [7, 0]
nums = [1, 0, 0, 2, 0, 3]
solution.moveZeroes(nums)
assert nums == [1, 2, 3, 0, 0, 0]
```

逐块对应你的思路：

- `write`表示“下一个非零数要放的位置”，也等于目前已保留的非零数数量。它代替了新列表的增长进度。
- `read`逐个检查原列表。遇到0时没有需要保留的新值，因此write不动。
- 遇到非零数，把值放到`nums[write]`，然后让write前进。write不会跑到read前面，所以不会覆盖尚未读到的后续元素。
- 所有非零数按遇到的先后顺序放好后，剩下的位置全部补0。这里要覆盖旧值，不是append增加列表长度。
- 两次线性扫描仍是O(n)时间，只有几个整数状态，额外空间O(1)。

手算`[0, 4, 0, 2]`：

| 此次读取 | write变化 | 原列表内容 |
|---|---|---|
| 下标0，值0 | 0不变 | `[0, 4, 0, 2]` |
| 下标1，值4 | 0变1 | `[4, 4, 0, 2]` |
| 下标2，值0 | 1不变 | `[4, 4, 0, 2]` |
| 下标3，值2 | 1变2 | `[4, 2, 0, 2]` |
| 把有效部分之后的位置补0 | write仍为2 | `[4, 2, 0, 0]` |

中途出现重复4或2是旧位置还没整理，不是最终答案。前两项已经放好之后，尾部仍需要处理。

不要用`nums = prefix_nmus`试图修复原地要求，那只是让函数中的名字改指向新对象。把新列表整体复制回去虽然能改变原列表，仍占O(n)辅助空间；它不是这次练习的最终目标。

### 2. 344：反转字符列表

```python
class Solution:
    def reverseString(self, s):
        left = 0
        right = len(s) - 1
        while left < right:
            s[left], s[right] = s[right], s[left]
            left += 1
            right -= 1


solution = Solution()
letters = ["p", "y", "t", "h", "o", "n"]
result = solution.reverseString(letters)
assert letters == ["n", "o", "h", "t", "y", "p"]
assert result is None
letters = ["z"]
solution.reverseString(letters)

solution.reverseString(letters)
assert letters == ["m", "n", "m"]
letters = ["u", "v"]
solution.reverseString(letters)
assert letters == ["v", "u"]
```

```python
class SingleNeuron:
    def __init__(self, weight, bias):
        self.weight = weight
        self.bias = bias

    def forward(self, x):
        z = self.weight * x + self.bias
        if z > 0:
            return z
        return 0


class RegressionDataset:
    def __init__(self, xs, ys):
        self.xs = xs
        self.ys = ys

    def size(self):
        return len(self.xs)

    def get_item(self, index):
        return self.xs[index], self.ys[index]


train_data = RegressionDataset([-1, 0, 1, 2], [-1, 1, 3, 5])
test_data = RegressionDataset([3, 4], [7, 9])

neuron = SingleNeuron(2, 1)
for index in range(train_data.size()):
    x, target = train_data.get_item(index)

    print(x, target, prediction)

assert train_data.ys == [-1, 1, 3, 5]
```

## 四、Python新内容：列表长度与“有效结果长度”可以不同

### 1. 原题究竟要你交付什么

今天是简单题[26删除有序数组中的重复项](https://leetcode.com/problems/remove-duplicates-from-sorted-array/)。输入已经按**非递减顺序（non-decreasing order）**排列，也就是后面的数不会比前面的数小，但允许相等。

例如`[-2, -2, 0, 0, 3]`有三个不同数。题目要你在原列表开头依次留下`[-2, 0, 3]`，并返回数字3。后面两个位置不作为答案检查。

**有效前缀（valid prefix）**是列表开头那段已经整理好的结果。人话：原来有五个格子，现在只告诉调用方“前面三个格子有效”，不要求把剩余格子拆掉。

| 返回值k | 原列表前k项 | 后面的项 |
|---|---|---|
| 3 | 必须是`[-2, 0, 3]` | 不参与答案检查，无需清零或删除 |

返回的是有效数量k，不是列表，不是最后一个有效下标。k=3时，最后一个有效下标是2。这一区别影响调用方怎样使用结果，不是为了背术语。

### 2. 它与昨天283是什么关系

两题都可以使用读写位置：阅读原数据，把需要保留的部分放到前面。但最终任务不同：

| 问题 | 什么需要保留 | 最后怎样交付 |
|---|---|---|
| 283 | 所有非零数，重复非零数也保留 | 整张原列表非零在前、0在后，长度不变 |
| 26 | 每个不同数仅保留一次，0也是正常数 | 返回有效数量，原列表前面对应部分正确，尾部不检查 |

所以不能把283最后的“补0”当成所有读写双指针题都需要的一步。先理解每题在保留什么，再决定写入和结束后的处理。

### 3. “有序”怎样帮你少做工作

因为相同数排在一起，一段相同值出现完，后面不会隔很远又冒出同一个更小的值。比如`[-2,-2,0,0,3]`中的两个0是连续的一组。

假设前面已经保留了`[-2, 0]`，再读到0不需要新增一个有效结果；读到3才出现了一个新的不同值。你不必为每次读到的数，在整个已见集合里再搜索一遍。

这与无序列表去重不同。这里输入已经有序，不需要你再调用sort，也不需要额外集合或字典。利用题目已经给出的信息，是算法思考的重要部分。

自己需要想清楚：第一个元素怎样参与有效结果？什么时候有效数量不变？怎样判断当前数是否增加一个新值？如何避免写入覆盖尚未读取的数据？这些问题由你写进自己的三步分析，不给完整循环或预填步骤。

目标是O(n)时间、O(1)额外空间，不能另外创建一张随着输入增长的结果表。保留“按顺序写入”的正确想法，练习把存储位置放对。

### 4. 怎样检查“前k项”，而不是误检查整张列表

Python的`values[:k]`表示从开头取到下标k之前，不包含k，得到一份前k项的列表。例如：

```python
values = [2, 5, 8, 8, 8]
k = 3
assert values[:k] == [2, 5, 8]
```

切片在这里仅用于测试结果，确实会建立小副本；不要把切片复制当作你的原地算法实现。测试辅助数据的内存与待测方法自己的额外空间分开计算。

测试时先保存输入，调用removeDuplicates得到k，再检查k和输入的前k项。这不是只检查一个返回数字；若返回3但原列表没有整理，仍然不正确。

## 五、C++：从一串数字输入到简单文本处理

### 1. char与string分别装什么

以前的int装整数。现在需要处理“loss”“gpu_0”这类名字：单个字符使用`char`，一串字符使用`std::string`。

人话：char是一格，string是一排格子。本课只处理英文字母、数字、下划线；这些ASCII字符各占一个字节。UTF-8中文不能简单按一个char等同一个汉字，今天不加入编码处理。

```cpp
#include <iostream>
#include <string>

int main() {
    char mark = 'p';
    std::string word = "gpu_0";
    std::cout << mark << '\n';
    std::cout << word << '\n';
    return 0;
}
```

输出p和gpu_0，各一行。`<string>`提供字符串类型，`<iostream>`提供输入输出。char字面值使用单引号，如`'p'`；字符串字面值使用双引号，如`"p"`。一个字符长度的字符串仍不是同一种写法，不照搬Python中单双引号通常都表示字符串的习惯。

`std::`表示使用标准库里的名字，不是每次要自己定义一个类。今天仍用现成类型，不学习C++类、指针或继承。

### 2. 长度和下标如何对应

字符串的`size()`返回其中char元素的数量，`word[index]`读取对应位置。下标从0开始。今天限定输入长度最多30，因此可以用int变量接收长度来练普通循环；size本身返回适合容器长度的无符号类型，后面再系统处理类型范围。

```cpp
#include <iostream>
#include <string>

int main() {
    std::string word = "gpu_0";
    int length = word.size();
    char first = word[0];
    char last = word[length - 1];
    std::cout << length << '\n';
    std::cout << first << '\n';
    std::cout << last << '\n';
    return 0;
}
```

依次输出5、g、0。长度是5，不代表最后一个内容在下标5；最后一个是4。把word改为`"A"`时，长度1，首尾都是A。

循环访问内容时只访问0到length−1，不把终止位置当成普通字符。无需讲C风格字符串的结尾机制；本课目标是正确使用string的内容范围。[C++标准字符串说明](https://learn.microsoft.com/en-us/cpp/standard-library/basic-string-class?view=msvc-170)

### 3. 怎样读入字符串与字符

`std::cin >> word`读取一个不含空白的字符串；`std::cin >> target`可以读入一个char。下面只演示输入与比较，不给字符计数循环：

```cpp
#include <iostream>
#include <string>

int main() {
    std::string word;
    char target = 'a';
    std::cin >> word >> target;
    std::cout << word.size() << '\n';
    if (word[0] == target) {
        std::cout << 1 << '\n';
    } else {
        std::cout << 0 << '\n';
    }
    return 0;
}
```

输入`apple a`，输出5和1；输入`apple p`，输出5和0。这个程序只检查首字符，不统计整串字符。

比较使用`==`，不是赋值用的`=`。大小写按不同字符处理，`'G'`不等于`'g'`。今天不读带空格的整行，不加入getline，也不要求空字符串输入。

## 六、教材2.2.1：先问“能不能表达”，再问“参数怎么学”

今天核对[本地《神经网络与深度学习》](../../学习资料/AI%20agent/神经网络与深度学习%20%28邱锡鹏%29.pdf)第2.2.1节，**书内25页至26页上部，PDF阅读器40—41页，公式(2.5)—(2.8)**。使用同一批人工数据继续讲，不换成无关的面向对象例子。损失和梯度分别留给后续课。

### 1. 昨天的差异，不一定能靠多练几次参数解决

昨天已有数据`x = -1`、目标`y = -1`。你的神经元先算`2×(-1)+1=-1`，再用ReLU把它改成0。代码按设计执行了，但预测不是目标。

想象我们不停换weight和bias：能不能让**这个最后一步仍然是ReLU的单神经元**输出−1？不能。因为无论前面的数是什么，ReLU输出都不小于0。

这说明学习之前要区分两种困难：一是参数暂时没选好；二是模型规定的计算形式根本不能给出需要的答案。后者不能仅靠在同一种形式里换参数解决。

### 2. 输入空间、输出空间为什么放在模型章节开头

**输入空间（input space）**指允许给模型哪些输入；**输出空间（output space）**指任务允许或需要哪些答案。人话：先看题目能给什么，答案可以是什么。

今天任务输入是一个数，目标也可以是负数、零或正数。模型如果把所有负输出截断，就限制了自己能给出的答案。不是标签错了，更不是“数据集应该把−1改成0”。

教材用x表示输入，y表示真实目标，用函数g描述背后的真实关系。真实工作里通常不知道g；我们只能用模型去近似。这里故意使用人工关系`y=2x+1`，是为了看清原因和检查实现，不表示真实问题都提前知道答案公式。

### 3. 假设空间：允许模型从哪一类关系中找答案

**假设空间（hypothesis space）**是我们允许模型选择的一组候选函数。人话：先决定使用哪一类尺子或曲线，再在这一类里调整具体形状。

如果选择`f(x)=w×x+b`，改变w和b就得到一组不同直线：

| w、b | 对应函数 | x=−1、0、1时的输出 |
|---|---|---|
| 0、0 | 恒为0 | 0、0、0 |
| 1、0 | 输出x | −1、0、1 |
| 2、1 | 输出2x＋1 | −1、1、3 |

这三条只是整个候选集合里的三个成员，不是只能从三条中选择。DAY18的候选权重搜索，是从很小的候选范围中挑一个；之后的梯度下降会用更有效的方式更新参数，但仍受模型形式约束。

公式(2.5)中的θ（theta）把一组参数统称起来；本课就是w与b这两个数。`f(x; θ)`可读成“给定这些参数时，模型怎样处理x”。四条样本、每条一个特征、两个模型参数，是三个不同数量，不要把它们都当成列表长度。

**选择模型形式**与**选择这份模型里的参数**也不是同一件事。决定最后是否用ReLU是形式上的选择；保持公式不变，把w从1改成2是参数变化。

### 4. 线性模型为什么适合今天这组关系

机器学习里通常把`w×x+b`称为**线性模型（linear model）**。w控制输入变化时输出怎样跟着变化，b把整体输出上移或下移。

固定w=2时，输入增加1，输出增加2；固定x不变，把b增加1，输出也增加1。例如x=−1、w=2、b=1时，输出直接是−1，不再经过截断。

教材公式(2.6)写成向量形式`wᵀx+b`。今天只有一个输入特征，它就是`w×x+b`；不用在没学矩阵前背转置符号。以后多个输入时，才把每个输入乘对应权重再加起来。

把线性输出和原ReLU输出放在同一批数据上看：

| x | 目标y | 线性输出2x＋1 | ReLU(2x＋1) |
|---|---:|---:|---:|
| −1 | −1 | −1 | 0 |
| 0 | 1 | 1 | 1 |
| 1 | 3 | 3 | 3 |
| 2 | 5 | 5 | 5 |

选择能输出负数的形式解决了这里的一处表达限制，但现在w=2、b=1仍是人工设置，不是训练出来的。不要因为四个答案都吻合，就把forward称为fit。

### 5. 那是不是线性模型永远比ReLU好

不是。我们只证明了“给这个任务的最终输出加ReLU会拦住负答案”，没有证明ReLU没有价值。

例如另一个关系，在x为−1、0、1时，目标分别是1、0、1，形状像V。若一条直线要通过(0,0)，b就得是0；还要通过(1,1)，w就得是1。此时它在x=−1只能输出−1，无法同时满足第三点的目标1。

这说明一条直线也有表达限制。**非线性模型（nonlinear model）**引入不能整体合并成一条直线的变换，用于表达更复杂关系。但单个ReLU也不自动解决所有非线性任务，不能把“非线性”理解为“万能”。这个V形例子只需手算，不新增一题网络实现。

教材(2.7)中的φ(x)表示先把输入变换成一些特征，再组合它们；(2.8)进一步让这些变换本身也带可学习参数，于是与神经网络连接起来。你DAY20把第一个神经元的输出交给第二个，就是“先形成中间表示，再继续计算”的最小体验。

真实网络可以在中间使用ReLU，而在需要预测任意实数的最后一层使用不截断的线性输出。因此“这一个ReLU输出层不适合负目标”，不等于“所有神经网络都不能预测负数”。我们会逐步学习怎样选择和组合部件，不在今天扩展到多层训练。

### 6. 模型选择之后，还缺什么

至此我们知道数据是什么、怎样交给模型、某种模型能表达什么。但同一种线性模型里，w=1与w=2究竟谁更好？对多条样本，是不是只看其中一条就够？

这就自然需要一个把预测偏差变成数字的评判方法，下一节教材2.2.2的学习准则与平方损失正是解决这个问题。再往后才轮到“朝哪个方向改参数”和“重复更新”。今天不提前塞给你梯度公式。
