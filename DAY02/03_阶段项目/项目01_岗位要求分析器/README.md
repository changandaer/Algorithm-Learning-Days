# 项目01：岗位要求分析器

GitHub计划仓库名：`job-skill-analyzer`

## 这个项目解决什么问题

招聘信息通常写得很长，初学者容易被一堆名词带着跑。这个项目会读取经过匿名化和人工概括的岗位摘要，统计重复出现的技能，最后输出CSV表格和Markdown报告。

项目不是为了做复杂的AI，而是让你通过一个真实问题逐步掌握Python、终端、测试和Git。

## 输入和输出

输入：一行一条的匿名岗位摘要，例如`data/示例岗位摘要.txt`。

最终输出：

- 技能出现次数CSV。
- 按共同基础、方向能力和厂商专项分类的Markdown报告。
- 对无效文件、空行和未知技能的清楚提示。

计划中的最终命令形式：

```bash
python -m job_skill_analyzer \
  --input data/示例岗位摘要.txt \
  --csv reports/技能统计.csv \
  --markdown reports/岗位能力报告.md
```

这只是最终接口说明，目前不能运行。课程会让你逐步把它做出来。

## 两周内怎样长出来

顺序会根据每日掌握程度调整：

1. 变量和输出：先做一张岗位学习卡。
2. 字符串和列表：保存多条岗位要求。
3. 判断和循环：逐条检查技能。
4. 字典：累计技能出现次数。
5. 文件：读取匿名岗位摘要。
6. 函数：把读取、统计、输出拆开。
7. 异常：处理文件不存在和内容为空。
8. CSV、模块和测试：形成可复现的小项目。
9. Git分支和合并：模拟团队增加一项功能。
