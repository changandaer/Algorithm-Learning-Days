## 当前常用词

| 词 | 人话解释 |
|---|---|
| 变量 variable | 贴了名字、用于保存数据的盒子 |
| 字符串 string | 一段文字 |
| 整数 integer | 没有小数部分的数字 |
| 布尔值 boolean | 只有真或假两种状态 |
| 条件判断 conditional statement | 根据条件选择执行哪一段代码 |
| 仓库 repository | Git负责记录历史的项目文件夹 |
| 提交 commit | 给项目状态拍一张带说明的快照 |
| 张量 tensor | 能装多维数字的容器，PyTorch处理数据的基本对象 |
| 梯度 gradient | 参数往哪个方向改变会让损失变化，以及变化多快 |
| DDP | 每张GPU放一份模型，各算不同数据，再同步梯度 |
| FSDP | 把参数、梯度和优化器状态拆到多张GPU以节省单卡显存 |

词典随课程增加，不要求现在背后半部分。
