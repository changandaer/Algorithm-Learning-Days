## 35分钟：理解if

现实中经常根据条件做选择：

```text
如果下雨，就带伞；
否则，不带伞。
```

Python把这种思路写成：

```python
is_raining = True

if is_raining:
    print("带伞")
else:
    print("不带伞")
```

冒号后的缩进表示“这行代码属于这个条件”。Python通常使用4个空格。没有正确缩进，程序会报错或产生错误逻辑。

常用比较符号：

| 写法 | 意思 |
|---|---|
| `a > b` | a大于b |
| `a < b` | a小于b |
| `a == b` | a和b的值相等 |
| `a != b` | a和b的值不相等 |

特别注意：

- `a = 5`：把5放入变量a。
- `a == 5`：询问a是否等于5，结果是`True`或`False`。
