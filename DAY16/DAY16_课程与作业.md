### 00：LC217存在重复元素

```python
class Solution:
    def containsDuplicate(self, nums):
        seen = {}
        for num in nums:
            if num in seen:
                return True
            seen[num] = True
        return False


solution = Solution()
assert solution.containsDuplicate([1, 2, 3, 1]) == True
assert solution.containsDuplicate([1, 2, 3, 4]) == False
assert solution.containsDuplicate([-2, 0, -2]) == True
assert solution.containsDuplicate([7]) == False
assert solution.containsDuplicate([]) == False
```

你的实现正确。`seen[num] = seen.get(num, 0) + 1`并没有错，但第二次遇到一个数时已经返回，所以字典里保留的计数实际上不会增长到2。示范用`True`只表示“见过”，不另外引入集合。

需要理解的是“先检查之前是否出现，再记下当前数”，不是必须照着示范换写法。平均时间O(n)，额外空间最坏O(n)；这里的数字种类会随输入增长，没有固定26种字符的限制。

```cpp
#include <vector>
#include <cassert>

int total_time_ms(std::vector<int> times_ms) {
    int total = 0;

        total += value;
    }
    return total;
}

int count_slow_steps(std::vector<int> times_ms, int threshold) {
    int count = 0;
    for (int value : times_ms) {
        if (value >= threshold) {
            count += 1;
        }
    }
    return count;
}

int main() {
    std::vector<int> sample = {80, 120, 100, 90};
    std::vector<int> no_steps = {};
    std::vector<int> one_step = {100};
    std::vector<int> zero_times = {0, 0};
    assert(total_time_ms(sample) == 390);
    assert(count_slow_steps(sample, 100) == 2);
    assert(count_slow_steps(sample, 121) == 0);
    assert(total_time_ms(no_steps) == 0);
    assert(count_slow_steps(no_steps, 100) == 0);
    assert(total_time_ms(one_step) == 100);
    assert(count_slow_steps(one_step, 100) == 1);
    assert(total_time_ms(zero_times) == 0);
    assert(count_slow_steps(zero_times, 0) == 2);
    return 0;
}
```

这里沿用DAY15的值传参，传入现有vector会产生元素副本；当前版本计入副本的额外空间是O(n)，遍历自身只用固定数量的累计变量。暂不要求你改写`const`引用版本。这是以后讲清楚复制后才做的改进，不是本次必学内容。

### 03：单输入神经元

```python
class SingleNeuron:
    def __init__(self, weight, bias):
        self.weight = weight
        self.bias = bias

    def forward(self, x):
        z = self.weight * x + self.bias
        if z > 0:
            return z
        return 0


first = SingleNeuron(2, -1)
second = SingleNeuron(-1, 2)
assert first.forward(3) == 5
assert first.forward(0) == 0
assert first.forward(0.5) == 0
assert second.forward(3) == 0
assert second.forward(-1) == 3
assert first.forward(3) == 5
assert first.weight == 2
assert first.bias == -1
assert second.weight == -1
assert second.bias == 2
```

你的计算结果全部正确，两个对象也确实各用自己的参数。`if ReLU > 0`在零点返回0，与ReLU定义一致，不需要为了`>`和`>=`纠结。

示范只有两个有用的简化：把激活前的值叫`z`，避免把“一个数”和“ReLU运算”混在一起；计算后直接返回`z`，不再重复乘加。变量名不是本次扣分项，重点是你能说出它代表什么。

你在理论中写“输入x来自实例对象”，还需要分清调用过程：对象提供参数，x由调用者这一次传给方法。代码实际写对了，所以今天用小实验把口述与实现对齐，不重写整个网络。

## 四、C++补足第一步：每个工具都看名称、用法和结果

本节只有一条学习线：看懂一个小程序怎样使用标准工具处理一组整数。不让你同时掌握两个函数、引用和索引循环。

### 1. `#include`为什么写在前面，尖括号里的是什么

头文件（header）提供其他代码使用某些类型、对象或功能所需的信息。标准库（standard library）是C++提供的一组通用工具，不是你必须自己从零实现的内容。

`#include`是预处理指令（preprocessor directive），在正式分析这份源代码之前引入指定头文件的内容。人话：你后面要使用工具，先让编译器知道这些工具是什么；它不是运行时才执行的一次函数调用。[include说明](https://learn.microsoft.com/en-us/cpp/preprocessor/hash-include-directive-c-cpp?view=msvc-170)

今天统一把头文件写在文件最前面，让后面的函数能够使用。不意味着任何程序固定都要写同样三行，而是根据实际用到的工具选择：

| 头文件 | 名称怎样理解 | 今天用它做什么 |
|---|---|---|
| `<iostream>` | input/output stream，即输入/输出流 | 使用`std::cout`向终端输出 |
| `<cassert>` | C兼容的assertion工具头；`assert`是“断言”，不是需要硬凑的缩写 | 使用`assert(...)`检查一个条件 |
| `<vector>` | 提供vector顺序容器 | 使用`std::vector<int>`保存一组整数 |

“流”（stream）把数据看成按顺序读入或写出的内容。现在把输出流理解成“程序把数字或文字一段段送到终端”即可。[iostream说明](https://learn.microsoft.com/en-us/cpp/standard-library/iostream?view=msvc-170)

`cassert`开头的c体现它来自C标准库兼容头的命名方式，对应C中的`assert.h`。本课用C++写法`<cassert>`。`assert`是宏（macro），可暂理解为预处理时展开的检查工具，不是普通的`std::`函数；所以写`assert(...)`，不写`std::assert(...)`。今天不学习怎样定义宏。[cassert说明](https://learn.microsoft.com/en-us/cpp/standard-library/cassert?view=msvc-170)

尖括号`<...>`在`#include`这里表示按编译器配置的头文件搜索路径寻找文件，不是数学上的大小比较。头文件是本机开发工具已经提供的，不会因为写了这一行就在线下载。现在也不需要寻找某个名叫`iostream`的软件安装。

### 2. 输出、返回和断言各负责一件事

先看完整的小示例；它不涉及今天的容器作业：

```cpp
#include <iostream>
#include <cassert>

int main() {
    int minutes = 8;
    std::cout << minutes << '\n';
    assert(minutes == 8);
    return 0;
}
```

运行输出一行8。`std::cout`是标准输出对象，`std::`说明这个名字属于标准库的命名空间；`::`是在那个范围内找名字的符号。`<<`在这里把数据送入输出流，`'\n'`表示换行。你写的`"\n"`也能输出换行，不是之前代码的问题。

`assert(minutes == 8);`先判断等号两边的值是否相同。条件为真时不打印“通过”；条件为假时报告断言失败并终止。这是有意写下一个可以由程序检查的期望。

`return 0;`结束`main`并报告成功退出，不会替你检查每个业务结果。比如忘了写统计代码，程序仍可能执行到这里，所以需要断言。

今天继续使用不关闭断言的编译命令。不先学习`NDEBUG`等额外选项，也不用打印输出来代替所有检查。`#include`不是普通语句，末尾没有分号；赋值、输出、断言、return这些普通语句有分号。

### 3. vector里到底放了什么

`std::vector<int>`是存放整数的可变长顺序容器：可以依次装入多个整数，并按位置访问。`vector`在数学里也译作向量，但此处先认识它作为C++容器的行为，不需要先学线性代数。

```cpp
#include <vector>
#include <iostream>

int main() {
    std::vector<int> values = {4, 9};
    std::cout << values[0] << '\n';
    std::cout << values[1] << '\n';
    return 0;
}
```

输出两行，分别是4、9。

- `std::vector<int>`说“这一变量是一组整数”；`<int>`指定元素类型，与上面`#include`的尖括号不是同一种语法用途。今天不教模板实现。
- `values`是我们给这组数据起的名字。
- `{4, 9}`给出初始元素，位置从0开始，`values[0]`是第一个元素。
- 列表里有两个数，但没有`values[2]`。元素个数和最大有效索引不是同一个数。

### 4. `.size()`：询问现在有多少个元素

下面局部代码要写在`main`里面，文件顶部需要`<vector>`、`<iostream>`：

```cpp
std::vector<int> values = {4, 9};
std::cout << values.size() << '\n';
values.push_back(7);
std::cout << values.size() << '\n';
std::cout << values[2] << '\n';
```

输出依次是2、3、7。`size`是“大小”这个英文单词，这里具体指元素个数，不是所有数字之和，也不是占用多少字节。

`values.size()`的点号表示“问values这个对象”，括号表示调用它的成员函数（member function）；没有额外参数，因为它已经知道要查看哪一个vector。调用会返回一个计数值，不改变原数据。

`push_back`可按“把一项放到末尾”理解。调用前是`{4,9}`，调用后是`{4,9,7}`；不是覆盖第一个数。`size()`返回的是非负的计数类型，本日直接打印和比较即可，不增加类型转换任务。

### 5. `.empty()`：问是否一个元素都没有，不是清空

同样是`main`内部的局部示例，需要`<vector>`、`<iostream>`：

```cpp
std::vector<int> values = {};
std::cout << values.size() << '\n';
std::cout << values.empty() << '\n';
values.push_back(0);
std::cout << values.size() << '\n';
std::cout << values.empty() << '\n';
```

输出依次是0、1、1、0。为什么不是英文的true/false？因为`std::cout`默认把布尔真输出成1，假输出成0；今天先使用这个默认行为，不额外教格式控制器。

`empty`是“空”的意思，`empty()`返回布尔值。最开始确实没有元素，所以为真；加入一个0后，虽然数值为0，但容器已经有一个元素，因此不空。它不会移除任何元素，连续问十次也不会把数据清掉。[vector的empty与size](https://learn.microsoft.com/en-us/cpp/standard-library/vector-class?view=msvc-170)

在断言里可以直接写`assert(values.empty() == false);`，这样是在检查“它不是空容器”，并不要求先把结果打印出来。今天不要求记忆“真对应1”，而要先知道这个条件到底在问什么。

空容器没有首项和末项。不要对它使用`values[0]`或`values[values.size()-1]`；C++的`[]`不保证像Python那样用一个清晰的异常帮你拦住越界。今天只在明确非空的场景读取元素，不做越界实验。

### 6. 遍历会产生什么，累计变量怎样保留进度

你已经写出了打印正数的循环，这部分不是零基础重新来过：

```cpp
std::vector<int> values = {2, 5};
for (int value : values) {
    std::cout << value << '\n';
}
```

这是放在`main`里的片段。输出2、5。`value`是本轮取出的一个整数，不是整个vector；循环自己换到下一项。只打印并不会自动把数字加起来。

累计变量（accumulator）就是一个“记录已经处理到哪一步结果”的变量。例如先不要用循环，只看两次赋值的作用：

```cpp
int total = 0;
total += 4;
total += 6;
std::cout << total << '\n';
```

输出10。`total += 4`与`total = total + 4`表达同一次更新：先取原来的值，加上4，再把结果存回去。

| 时刻 | 处理前total | 本次加入 | 处理后total |
|---|---:|---:|---:|
| 尚未处理数据 | 0 | — | 0 |
| 加入第一项 | 0 | 4 | 4 |
| 加入第二项 | 4 | 6 | 10 |

为什么从0开始？还没有处理任何耗时时，总耗时就是0。为什么要在整段遍历开始前准备累计变量？因为它需要记住前面已经加过的结果；如果每轮重新设为0，前面的进度就丢掉了。

这里只给你理解语法的小片段，不把今天作业的整段遍历与统计替你拼好。今天用同一套三步分析，自己决定怎样让容器里的每项参与计算。

## 五、神经网络支线：参数属于对象，输入属于这次调用

今天沿用DAY15已讲过的单输入神经元，不增加数学前提：`z = weight * x + bias`，输出为`ReLU(z)`，即负数变成0，非负数保留。这里的重点是说清数值从哪里来，不是背模型外壳。

### 1. 从你自己的两个调用理解self与x

```python
class SingleNeuron:
    def __init__(self, weight, bias):
        self.weight = weight
        self.bias = bias

    def forward(self, x):
        z = self.weight * x + self.bias
        if z > 0:
            return z
        return 0


neuron = SingleNeuron(2, -1)
first_result = neuron.forward(3)
second_result = neuron.forward(4)
assert first_result == 5
assert second_result == 7
```

这段复现的是DAY15已经做对的模型，不是新题答案。读调用就能发现：实例`neuron`没有变，权重与偏置没有变；变化的是括号里由调用者写下的3与4。

调用`neuron.forward(3)`时，Python把`neuron`自动交给`self`，把你提供的3交给x。下一次`neuron.forward(4)`，x收到4，而不是从对象内部自动生成的某个数。[Python实例方法的参数传递](https://docs.python.org/3.11/tutorial/classes.html#method-objects)

| 一次调用中 | 来源 | 调用结束以后 |
|---|---|---|
| `self` | 通过哪个对象调用，便指向那个对象 | 对象仍可被其他变量引用 |
| `self.weight`、`self.bias` | 创建实例时保存的属性 | 对象仍在时，可继续用于下次计算 |
| `x` | 调用者本次提供的数值 | 本方法不把它保存为实例属性 |
| `z` | 本次乘加计算 | 是本次调用的局部中间结果 |
| 返回的数值 | 由本次x和当前参数算出 | 调用者可以接住它、打印或测试 |

以后x可以来自文件或一批训练样本，具体输入由调用方安排；“输入给某个对象”不等于“输入来自该对象”。方法也不必把所有局部变量都改成`self.xxx`。

### 2. 为什么要分别测试两个实例

只测试一个对象、一组参数时，即使有人把权重写死成2、偏置写死成-1，也可能碰巧通过。换成另一个参数不同的对象，就能检查代码有没有真的读取当前实例的属性。

这不是要求你怀疑自己的每行代码，而是在核对模型最基本的含义：“每一份模型到底使用哪一组参数”。你现在代码已通过我的测试，今天需要你自己设计并解释这样的检查。

比如A使用w=2、b=-1，B使用w=3、b=1。同样输入x=2，A的结果是3，B的结果是7。两者使用同一个类，但不是同一份参数。

这里要区分两件事：分别写两次`SingleNeuron(...)`才创建两个实例；如果只把同一个对象赋给另一个变量名，就不是新建一份模型。今天不涉及列表属性或深拷贝，先把这个区别认识清楚。

### 3. 改输入、改参数、训练，分别是什么

- 改输入：同一个模型本次看3，下次看4；参数可以不变。
- 改参数：例如给已有对象的`weight`属性赋一个新数，之后的计算使用新数。
- 训练：依据数据、目标和误差，用学习规则调整参数。仅手工把权重改成3，不能称作模型从数据中学到了3。

在这个普通Python类里，`forward`只是我们约定的方法名。它不会因为名字叫forward而自动反向传播；执行的就是你写进去的语句。目前没有参数更新语句，因此只是在计算输出。

后续仍会逐渐加入多输入、层的组合、损失与梯度。今天先不升级，避免代码会写、概念还没对上就进入更大模型。
