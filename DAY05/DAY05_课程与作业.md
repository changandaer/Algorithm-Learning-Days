## 四、新知识：列表是一排有编号的储物格

### 1. 为什么需要列表

如果要保存五项技能，可以建立五个变量：

```python
skill_1 = "Python"
skill_2 = "C++"
skill_3 = "Linux"
```

但当技能数量由用户决定时，我们事先不知道要建立多少变量。**列表（list）**就是一个能按顺序保存多个值的容器：

```python
skills = ["Python", "C++", "Linux", "Git"]
```

可以把它想成一排储物格。列表有一个名字 `skills`，每个格子还有自己的编号。

### 2. 索引从 0 开始

**索引（index）**就是元素在列表中的位置编号：

```python
skills = ["Python", "C++", "Linux"]

print(skills[0])  # Python
print(skills[1])  # C++
print(skills[2])  # Linux
```

三个元素的有效索引是 0、1、2。访问 `skills[3]` 会出现 `IndexError`，人话就是：“你打开了不存在的第四个格子。”

`len(skills)` 得到元素数量 3，所以最后一个有效索引永远是 `len(skills) - 1`。

### 3. 列表可以修改

```python
skills = ["Python", "Linux"]

skills.append("Git")   # 在末尾增加一个元素
skills[0] = "Python 3" # 修改第一个元素

print(skills)
print(len(skills))
```

今天重点使用：

- `append(value)`：在末尾追加一个值。
- `len(list_name)`：获取元素数量。
- `value in list_name`：判断值是否已经存在。
- `value not in list_name`：判断值是否不存在。

方法名不需要死背。你要知道“列表能够追加、查询、修改”，忘记准确拼写时可以查文档或问 AI。

### 4. 两种遍历方式

**遍历（traversal）**就是按顺序看过容器里的每个元素。

只关心元素内容时，直接遍历值：

```python
skills = ["Python", "C++", "Linux"]

for skill in skills:
    print(skill)
```

同时需要位置时，遍历索引：

```python
for index in range(len(skills)):
    print(index + 1, skills[index])
```

程序内部索引从 0 开始，但展示给人看时通常从 1 开始，所以输出使用 `index + 1`。

不要在遍历列表时随意删除当前列表中的元素。这样会让后面的格子突然前移，容易漏掉数据。删除和更复杂的修改以后单独学习。

### 5. 字符串清理：`strip()` 和 `lower()`

用户可能输入 `" Python "`、`"PYTHON"`、`"python"`。对人来说是同一项技能，对计算机来说原本是三个不同字符串。

```python
raw_skill = input("请输入技能：")
clean_skill = raw_skill.strip().lower()
```

- `strip()` 去掉开头和结尾多余空格。
- `lower()` 把英文字母转成小写。

这叫**标准化（normalization）**：先把不同写法整理成统一格式，再进行比较。

### 6. `split()`：把一行文字拆成列表

```python
text = "python linux git"
skills = text.split()
print(skills)
```

输出相当于：

```python
["python", "linux", "git"]
```

今天只使用最简单的空格拆分。以后处理真实岗位文本时，还会遇到中文标点、斜杠和换行，那时再逐步增强。

### 7. 线性查找：从头找到尾

**线性查找（linear search）**就是从第一个元素开始逐个比较，找到目标或走完整个列表：

```text
先假设没有找到
依次查看列表里的每项技能
    如果当前技能等于目标
        记录已经找到
        结束查找
根据结果输出
```

如果列表有 `n` 个元素，最坏情况要比较 `n` 次，记作 **O(n)**。先把它理解成：“数据增加十倍，最坏工作量大约也增加十倍。”现在不要求背复杂度定义，但每个算法都要开始问一句：数据变多时，它会慢成什么样？

### 8. 嵌套循环：每个元素再配对其他元素

```python
numbers = [2, 7, 11, 15]

for first_index in range(len(numbers)):
    for second_index in range(first_index + 1, len(numbers)):
        print(numbers[first_index], numbers[second_index])
```

外层选第一个数，内层只从它后面选第二个数，因此不会让同一个元素和自己配对，也不会同时出现 `2, 7` 与 `7, 2`。

这种两两配对在最坏情况下大约要检查 `n × n` 次，记作 **O(n²)**。数据扩大十倍，工作量可能扩大约一百倍。今天只在挑战题使用，后面学习哈希表时会把“两数之和”优化到 O(n)。
