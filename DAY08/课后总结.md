1. 函数的参数和调用时传入的实际数据有什么区别？
函数的形参更像是一个占位符，实际传入的数据实参是真正调用函数开始工作的

2. `return` 与 `print()` 的区别是什么？为什么 LeetCode 更关心 `return`？
`return` 可以将结果赋值给参数，方便后续继续调用处理这个结果，但是`print()`只能把结果显示出

3. 为什么函数内部的计数器每次调用都能从 0 开始？
因为每次调用都会建立新的 `current_count = 0`

4. `return index` 为什么可以同时代替 `found = True` 和 `break`？
`return`能直接终止函数工作

5. 函数合同至少应该写清哪些内容？
函数名、函数输入（形参）、输出（return）

6. `assert` 有什么作用？测试正确时为什么通常没有输出？
`assert`测试给定的输入是否有预期的输出结果，测试正确就没有任何返回值，测试报错就意味着预期的输出结果与真实的输出结果不符

7. 为什么不需要学完继承、多态和所有魔术方法才开始 Hot 100？
**LeetCode Hot100 核心考的是「数据结构 + 算法思想」，不需要系统学习封装、继承、多态这类完整面向对象知识**
- Python 提交模板里自带`class Solution`，**这只是平台固定格式，不是考察 OOP 封装能力**
- 只有链表、二叉树、LRU 缓存等少量题目需要**简单自定义类（ListNode、TreeNode）**，只用基础`__init__`，不用封装、私有变量、继承等复杂 OOP
- 面试手撕 Hot100 阶段：**优先刷算法，OOP 封装可以后置**；只有后面遇到系统设计题（OOD）才会重点考封装
